## Sistema para Leitura de Quadrinhos .cbr/.cbz

> Escolha a pasta onde estão seus quadrinhos ou mangas em configurações que ele vai escanear

FUNÇÕES:
	- Ultimo quadrinhos Lidos (exibe ultima página lida, se completou)
	- quadrinhos não lidos (todos os quadrinhos escaneados que nunca foram lidos no sistema)
	- Marcados como favoritos (separa por pasta apenas os quadrinhos favoritados)
	- Minha coleção, exibe todos os quadrinhos organizados por pasta e separados.
	- Quando finaliza um quadrinho ele fica com card amarelado e uma estrela.
	- Sistema de leitura: com miniaturas, marcar como favorito, identifica ultima página lida, ajuste de imagem
	- Biblioteca: é onde exibe toda a coleção identificando quais foram lidos e quais não foram
	- Favoritos: onde guarda os quadrinhos marcados como favoritos, organizando por pastas
	- Histórico: Regista últimos quadrinhos lidos, páginas lidas, local do quadrinho etc...
	- Perfil: N/D
	- Configurações: Registra local da pasta onde está os quadrinhos, limite de novos HQ e Favoritos.
